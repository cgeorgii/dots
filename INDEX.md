# Roadmap index

The record of every roadmap ID, open, finished or dropped. Adding a row here is
what creates an ID; IDs are never reused. Status lives in the item itself; this
index only says where the item is. Conventions are in [ROADMAP.md](ROADMAP.md).

## Areas

1. **system**: NixOS, boot, hardware, network, security
2. **desktop**: compositor, bar, launcher, notifications, theming
3. **tooling**: development tools, shell, editor, workflow
