# Introduction

This manual covers how to operate coco, the NixOS system this repository
defines: the things that are done by hand rather than read off the
configuration, such as which commands to run and in what order.

How the repository is laid out and how features are written is not covered
here; the comments in `modules/` and the roadmap hold that.

Read it with `dots-manual` from the dev shell, which serves the book on
localhost:3000 and rebuilds it on every edit.
